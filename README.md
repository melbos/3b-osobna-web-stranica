# 3.b — Osobna web stranica

Demonstracijski repozitorij za nastavu Informatike (3.b, PMG) — cjelina **"Mrežne stranice – moj kreativni web kutak"** (listopad 2026.).

Sadrži početni predložak (`index.html` + `style.css`) koji povezuje CSS s HTML stranicom i demonstrira:

- razliku između `<div>` (blok element) i `<span>` (linijski element),
- `font-family` s rezervnim (fallback) fontovima,
- osnovni CSS box model (`padding`, `margin`, `border`).
